For Windows:
The IRENE-AE9/AP9/SPM V1.58.001 distribution package includes the executable for PCs (32- and 64- bit), user's guide, documentation, license, and sample input/output files. The software includes both a graphical user interface version and a command line version for running the model.

This version is Distribution A: Approved for public release; distribution unlimited.
